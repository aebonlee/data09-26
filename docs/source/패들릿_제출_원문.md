## 게시물 1 — 「[2] 인증법규 Agent」 (08:52)

```text
제목: [2] 인증법규 Agent
건설기계 인증법규 지식 AI Agent
  Zero-Hallucination 기반 RAG 아키텍처 설계
 제품개발 · 영업 · 품질 부문 ↔ 인증팀 협업 혁신을 위한 사내 전용 인증법규 Q&A Agent
 2026. 09. 30




  1. 개요
  1.1 배경 및 문제 정의
 건설기계 사업은 판매 국가마다 배출가스·안전·소음·전자기적합성(EMC)·기능안전·형식승인 등 서로 다른 인증 규제가 적용되며, 규제는 지속적으로 개정된다. 현재 제품개발·영업·품질 부문은 인증 관련 문의를 인증팀에 개별적으로 요청하고 있어 다음과 같은 비효율이 발생한다.
 •     응답 지연 : 단순 반복 문의(“A국 수출 시 필요한 인증은?”)가 인증팀에 집중되어 병목 발생
 •     지식의 편재 : 법규 원문·해석·과거 사례가 개인 PC, 메일, 폴더에 분산되어 검색과 재사용이 어려움
 •     해석 편차 : 담당자에 따라 동일 규제에 대한 답변이 달라질 위험
 •     개정 추적의 어려움 : 법규 개정·시행일 변경이 현업에 적시에 전달되지 않음
  1.2 목적
 사내 M365 지정 폴더의 인증·규제 자료와 승인된 국가별 인증정보 링크를 지식원으로 하여, 현업의 인증 문의에  근거가 확인된 내용만  답변하는 사내 전용 AI Agent를 구축한다. 인증팀은 반복 문의에서 벗어나 고난도 해석과 지식 관리에 집중하고, 현업은 즉시 근거 기반 답변을 얻는다.
  1.3 범위
  구분
  내용
  사용자
 건설기계 제품개발·영업·품질 부문 및 인증팀 사내 인원 (지정 보안 그룹 소속자로 한정)
  지식원 ①
 사내 M365(SharePoint/OneDrive) 내  별도 지정된 폴더 에 저장된 인증규제 법규·지식 문서
  지식원 ②
 건설장비 관련 전세계 국가별 인증정보  링크 (별도 제공·승인된 목록)
  핵심 요구 ①
  할루시네이션 절대 금지  — 근거가 없으면 “확보된 지식이 없습니다”로 답변
  핵심 요구 ②
 답변 후  관련 추가 질문을 제안 하여 사용자가 스스로 원하는 답을 탐색하도록 지원
  2. 설계 원칙
  절대 원칙: “근거 없으면 답하지 않는다.”
 인증 답변은 사업 리스크(선적 지연, 인증 미취득 판매, 리콜)와 직결된다. 따라서 이 시스템은 ‘그럴듯한 답’보다 ‘틀리지 않는 답’을 우선하며, 확보된 지식으로 입증되지 않는 내용은 답변하지 않는다.


  #
  원칙
  설계 반영
  P1
 폐쇄 세계(Closed-world) 지식
 승인된 소스에서 수집·인덱싱된 내용만 답변 근거로 사용. LLM의 사전 학습 지식은 사실 근거로 사용 금지 (언어 이해·요약·표현 용도로만 사용)
  P2
 모든 문장에 출처
 답변의 모든 사실 문장은 문서명·조항·페이지·기준일이 있는 인용과 연결. 인용 없는 사실 문장은 출력 차단
  P3
 검증 후 출력
 생성된 답변을 별도 검증 단계가 근거와 대조(문장 함의·숫자·날짜·규격번호 일치)한 후에만 사용자에게 전달
  P4
 모르면 모른다고 답변
 검색 신뢰도 또는 검증이 기준 미달이면 고정 문구로 “확보된 지식이 없다”고 답변하고 대안(인증팀 문의) 안내
  P5
 시간 유효성 관리
 법규별 시행일·개정 이력·수집일을 메타데이터로 관리하고, 답변에 ‘기준일’ 표시 및 오래된 자료 경고
  P6
 탐색 지원
 답변 뒤에 ‘지식베이스에 실제로 답이 존재하는’ 후속 질문만 제안하여 자기주도 탐색을 유도
  P7
 최소 권한·감사 가능성
 사내 지정 그룹만 접근, 원본 문서 권한 상속, 모든 질의·근거·답변 로그를 감사 가능하게 보관


  정직한 전제 : LLM 기반 시스템에서 확률적 오류를 이론적으로 ‘0’으로 보장할 수는 없다. 따라서 본 설계는 “환각이 발생하지 않기를 기대”하는 대신,  환각이 사용자에게 도달하지 못하도록 다중 방어선을 구조적으로 두고 , 남는 잔여 위험은 출처 확인과 인증팀 검수로 관리하는 방식으로 ‘절대 원칙’을 구현한다.


 위의 내용은 클로드를 이용해 작성한 내용으로
 목적은 사내의 인증법규 업무와 관련된
 인증법규팀에서 정리한 전사 제품관련 인증법규 지식을 사내 지식 폴더(M365 원드라이브기반)
 사외 인증법규 링크(EN474 등)
 인증법규팀의 사내 시스템
 인증법규팀의 문의 지원요청 해결 방안을 정리한 이메일(별도 워드포멧으로 저장)
 을 기반으로 하여
 질문자의 문의 사항에 대한 답을
 "할루시네이션 0"에 근접한 수준으로 답변을 출력하는 사내 시스템 구현


 해당 시스템은 국핵기 기반은 아니나 사내한 지식으로 한정


 답변 내용에 맞는 지식을 못찾을 경우 "없음"으로 답하고 질문의 답에 대한 연계 필요 사항을 지속 문의 하여 질문자의 요구 사항을 구체화 하여 답을 출력 가능하도록 기능 추가


 지식 폴더 등에 대한 추가 기능 제공


 시스템 구성은 파이선등으로 구현 하고
 운영은
   사내 팔란티어관리팀의 지원을 받아 팔란티어어서 구현하는 방안 또는

  사내 PC를 통해 운영 가능한 수준

  의 두가지 기준에서 운영 가능함
```
