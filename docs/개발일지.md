## 결정과 이유

- **운영 형태 = 사내 PC 브라우저, 폐쇄망 우선.** 제출 원문은 「사내 전용」, 「Python 등으로 구현」, 「팔란티어 또는 사내 PC」 두 안을 적었습니다. 같은 제출자의 첫 과제(data09-15)도 폐쇄망 로컬 도구였습니다. 설치 권한이 없어도 바로 써 볼 수 있도록 1단계는 `index.html` 더블클릭으로 도는 정적 웹으로 하고, 외부 CDN · 외부 주소를 전혀 부르지 않게 했습니다. 로직은 화면과 분리한 순수 함수라 Python · 팔란티어로 옮길 때 그대로 규칙표가 됩니다(기획서 10장 질문 1).
- **LLM 없이도 도는 부분을 최대로.** 거절 · 되묻기 · 후속 질문 확인 · 사후 검증을 모두 규칙으로 하고, AI 는 근거 조항을 문장으로 정리하는 데만 씁니다. 설계 원칙 P1(사전 학습 지식은 표현 용도로만)과 「단순히 모르면 모른다고 답하라고 지시하는 것만으로는 부족하다」(G 6.3)를 그대로 옮긴 것입니다. 사내 LLM 은 OpenAI 호환 주소 · 모델만 적으면 자동으로 보내고, 없으면 복사 · 붙여 넣기로 씁니다.
- **근거 판정 = 핵심 낱말 비율.** BM25 점수는 문서 모음에 따라 크기가 달라 그것만으로는 「근거가 있다」를 말할 수 없습니다. 질문에서 질문 투 · 너무 흔한 낱말(기준 · 요건 · 인증 등)을 빼고 남은 핵심 낱말이 근거 조항(본문 + 그 문서의 국가 · 분야 · 제목)에 실제로 있는 비율로 충분(≥0.66) · 일부(≥0.34) · 없음을 가르고, 이유(없는 낱말)를 화면에 보여 줍니다. 「베타국 크레인 풍속 제한」은 베타국 문서가 검색되지만 크레인 · 풍속 · 제한이 없어 거절됩니다.
- **지식베이스에 없는 나라는 바로 거절.** 「독일」처럼 실제 국가 이름이 들어 있고 그 나라 문서가 없으면 검색 결과가 무엇이든 거절합니다(유사 국가 혼동 방지, G 13장 red team). 국가 판별용 목록만 있고 규정 내용은 없습니다. 「인도(引渡)」처럼 흔한 낱말과 겹치는 이름은 목록에서 뺐습니다.
- **조각 ID = 「문서코드 조항」.** 답의 인용([E1] → 조각 ID), 기록, 골든셋, DB 가 모두 같은 ID 를 씁니다. 「제2조(적용 범위) ① …」처럼 첫 항이 조 제목 줄에 붙어 있는 흔한 형식을 처음에 놓쳐 「제2조」 하나로 묶였고, 골든셋의 ROPS · 후방 시야 문항이 실패해서 찾았습니다. 부칙의 제1조가 본문 제1조와 겹치지 않도록 「부칙 제1조」로, 그래도 겹치면 「#2」를 붙입니다.
- **숫자 대조는 「인용한 조항 안에서」.** 근거 전체에서 숫자를 찾으면 다른 조항의 숫자(예: 질소산화물 0.35)를 입자상물질 문장에 붙여도 통과합니다. 그래서 문장이 인용한 조항에서만 찾습니다(테스트로 고정).
- **후속 질문은 다시 판정해서 통과한 것만.** 후보(앞뒤 조항 · 같은 나라 다른 분야 · 같은 분야 다른 나라)마다 검색 · 판정을 다시 돌리고, 심화 질문은 그 조항이 실제로 찾아지는지까지 봅니다(C 6.2). 근거 없음일 때도 같은 방식으로 「대신 확인할 수 있는 주제」를 보여 줍니다.
- **샘플은 가상.** 실제 규정 원문(EN 표준은 저작물)을 옮기지 않았고, 실제 수치와 헷갈리지 않게 숫자도 일부러 다르게 지었습니다. 문서 · 화면 · 배너 모두 「가상 샘플 — 실제 법규 아님」.
- **모든 질문을 기록.** 처음에는 근거 없음과 답 검증만 기록했는데, 되묻기 · 충분 판정 뒤 답을 붙이지 않은 질문이 빠져 감사 기록(P7)으로 부족해 모든 질문을 남기고 검증 때 같은 줄을 고치게 바꿨습니다.

## 결정과 이유

- **분야 판별 순서에서 사이버 보안을 맨 앞에.** 판별은 앞에서 처음 맞는 분야를 고릅니다. 「보안」과 「안전」이 함께 나오는 질문(원격 접속 보안 안전 요건)이 안전으로 잘못 읽히지 않게 했습니다. 다른 분야 질문(비상 정지 → 안전, 방사 내성 → EMC)은 그대로인지 테스트로 고정했습니다.
- **`ota` 같은 짧은 영문 낱말은 넣지 않음.** 분야 낱말은 글자 포함으로 찾으므로 total · quota 같은 낱말에 걸립니다. 대신 「무선 업데이트」를 넣었습니다.
- **샘플 숫자는 지어낸 값.** 실제 규정과 헷갈리지 않도록 기한(21일 · 60일 · 96시간 · 180일)과 보관 기간(7년 · 9년)을 일부러 흔한 실제 값과 다르게 잡았습니다. 문서 머리마다 「가상 샘플 — 실제 법규 아님」.
